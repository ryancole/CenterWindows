# CenterWindows
A program that re-positions windows at the center of the desktop.

## Usage
I typically assign a Windows hotkey to this application. I use it to center application windows on my desktop.

## Download
Grab `CenterWindows.exe` from the [latest release](https://github.com/ryancole/CenterWindows/releases/latest).

## Releasing
Push a version tag and the [release workflow](.github/workflows/release.yml) builds the exe and publishes it as a GitHub release.

```
git tag v1.0.0
git push origin v1.0.0
```
